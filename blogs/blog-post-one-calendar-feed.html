One Calendar Feed to Rule Them All

Paul Snider Technology Executive & MBA

I've written before about building a family calendar system, automating it with GitHub Actions, and keeping a weekly school digest running with Gemini. This post ties those threads together — because we just made a change that finally connects all three into a single source of truth.

The Problem with Multiple Sources

Earlier posts in this series covered each piece individually:

  • Taming the Chaos: Building a Family Calendar System for Three Kids — the original aggregation page pulling from GameChanger, TeamSnap, Blue Valley, and St. Michael
  • Automating Family Calendar Chaos with GitHub Actions — a Python script on a 6-hour cron that merges all the sports feeds into a single .ics file published to GitHub Pages
  • Bringing AI Into Everyday Life — a Google Apps Script that reads school emails and generates a Sunday digest with Gemini
  • Keeping the Weekly School Digest Alive with Gemini — updating that digest after ChatGPT lost its Drive connector

The issue: calendar feed URLs lived in two places. The GitHub Action had them in scripts/combine-calendars.py. The Google Apps Script had the same URLs hardcoded separately. Every time a team changed — new season, new GameChanger token — I had to update both. And they'd drift.

The Fix: One Feed, Two Consumers

The GitHub Action already produces a combined .ics file and publishes it to GitHub Pages every 6 hours:

https://pauljsnider.github.io/paulsnidernet/family/family-calendar-combined.ics

That file merges events from all sports calendars — Will's soccer, baseball, and indoor soccer, plus TeamSnap events for Madison, Max, and Will — and stamps a custom X-SOURCE-CALENDAR property on each event so consumers know which feed it originally came from. It also writes an X-COMBINE-TIMESTAMP header so anything reading the file knows how fresh it is.

We made two things point at that single URL.

Consumer 1: The Family Events Page

The calendar page was rebuilt as a hybrid. Sports events load from the combined .ics directly — same origin, no CORS proxy needed — while school calendars (Blue Valley, Overland Trail, St. Michael) are still fetched live from their source URLs. A "synced · Xm ago" badge reads X-COMBINE-TIMESTAMP from the file header to show freshness at a glance.

Each event's X-SOURCE-CALENDAR value drives two things: which virtual calendar checkbox controls its visibility, and which kid filter it appears under. The kid attribution logic looks like this:

  • mustangs / ote cougars / first grade boys → Will
  • jr current / wildcats softball / 4th grade girls → Madison
  • wildcats (catch-all) → Madison
  • prek / kindergarten / max snider / u6 → Max
  • calendar name contains "will soccer" or "will baseball" → Will
  • teamsnap with no specific title match → unattributed

The download button is a direct link to the combined file, so subscribing to the feed and viewing it in the browser both pull from the same place.

Consumer 2: The Weekly Google Apps Script Digest

The ICS_FEEDS array in the Apps Script went from three separate sport calendar URLs down to one:

const ICS_FEEDS = [
  {
    name: "Family Calendar",
    url: "https://pauljsnider.github.io/paulsnidernet/family/family-calendar-combined.ics"
  }
];

The script's parseIcs() function reads X-SOURCE-CALENDAR from each event and uses it as the source label — so "Will Baseball" and "Will Soccer" still appear correctly in the digest output even though they all came from one file. The same kid attribution rules that run in the browser run server-side in Apps Script, so the Sunday email labels events the same way the events page does.

The School Email Side

While we were in the Apps Script, we also expanded the Gmail search to cover 17 domains — not just school newsletters but TeamSnap notifications, Heartland Soccer, Blue Valley Rec, Peachjar flyers, SignUpGenius, and activity platforms like Amilia and Upper Hand. We updated the Gemini prompt to go deeper into Smore newsletter content, explicitly asking it to extract specific topics covered in class, upcoming tests and due dates, and action items for parents — not just a surface-level summary.

The full domain list the digest searches:

  • bluevalleyk12.org, cremedelacreme.com, cremeschool.com
  • online.procaresoftware.com, procaresoftware.com
  • stmichaelcp.org, stmichaelcp.ccsend.com
  • teamsnap.com, sportingbv.org, heartlandsoccer.net
  • peachjar.com, bluevalleyrec.org, jocogov.org
  • active.com, amilia.com, getupperhand.com, signupgenius.com

The Result

To update a sports calendar URL now, you change one line in scripts/combine-calendars.py. The next time the GitHub Action runs — within 6 hours — both the events page and the Sunday digest automatically reflect the change. No duplicate config, no drift, no stale URLs in a Google Apps Script that nobody remembers to update mid-season.

It's a small architectural change, but it's the kind that pays off every time a new season starts and GameChanger rolls a new token.
