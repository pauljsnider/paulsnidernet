## About

Leaf Shooter was Will's idea - a game where you shoot leaves falling from a tree. We used Google's new Antigravity AI IDE with its spec-driven workflow and browser automation to build this complete game in just 15 minutes.

## How to Play

### Objective
Shoot all the falling leaves before they reach the ground to score points.

### Controls

**Keyboard:**
- `W` / `↑` - Aim up
- `S` / `↓` - Aim down
- `A` / `←` - Aim left
- `D` / `→` - Aim right
- `Space` / `Click` - Shoot
- `R` - Restart game

**Touch Controls:**
- Use the on-screen directional pad to aim
- Tap the SHOOT button to fire

### Scoring
- Hit a leaf to score points
- Clear all leaves to win
- Miss too many and it's game over

## Development Story

This game was created as an experiment with Google Antigravity's agentic IDE. Instead of writing code line-by-line, we:

1. Described what we wanted
2. Let the AI agent plan, code, and test
3. Reviewed the Artifacts (documentation, screenshots, diffs)
4. Made tweaks through conversational feedback
5. Had a working game in 15 minutes

The autonomous agents handled everything from canvas setup to physics to browser testing.
