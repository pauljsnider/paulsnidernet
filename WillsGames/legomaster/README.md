## How to Play

### Objective
Stack falling Lego bricks to complete horizontal rows. Each completed row clears and awards points. Keep building without hitting the top!

### Controls

**Keyboard:**
- `←` / `→` - Slide brick left/right
- `↑` / `Z` - Rotate brick
- `↓` - Soft drop (faster falling)
- `Space` - Hard drop (instant placement)
- `R` - Restart game

**Touch Controls:**
- Toggle touch controls with the button
- Use on-screen D-pad for all movements
- Perfect for tablets and mobile devices

### Scoring
- **Single row:** 100 points
- **Double row:** 300 points
- **Triple row:** 500 points
- **Quad row:** 800 points
- Points multiply with level increases

### Levels
The game speeds up every 10 cleared lines. Can you keep up as the bricks fall faster?

## Development Story

This was one of the original games in Will's Arcade, built during a before-bed coding session. Will named it "Lego Master" after his favorite building toy, and we designed the colorful blocks to look like Lego bricks.

The game uses classic falling-block puzzle mechanics but with a kid-friendly Lego theme that made it approachable and fun for a first grader to play and understand.

## Tips for Master Builders

1. **Keep it flat** - Don't create tall columns, they'll trap you
2. **Use the preview** - Plan ahead with the "Next Brick" display
3. **Hard drop carefully** - Space bar is fast but unforgiving
4. **Clear multiple rows** - Bigger combos = bigger points
